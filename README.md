# Open Literature Map

Open Literature Map 是一個在本機瀏覽器中使用的文獻整理工具，協助你匯入自己的 PDF 論文、搜尋相關研究，並以互動關係圖探索文獻之間的連結。

## 可以做什麼

- 匯入本機 PDF 論文並建立個人文獻庫
- 依研究主題與關鍵字搜尋相關文獻
- 以引用、共同主題與內容相似度檢視文獻關係
- 依年份、來源、引用數與開放取用狀態篩選結果
- 收藏文獻、加上標籤，並從單一核心文獻延伸探索

## 使用方式

請先安裝 [Node.js](https://nodejs.org/)，再於專案資料夾執行：

```bash
node server.mjs
```

接著在瀏覽器開啟：

```text
http://127.0.0.1:8770/
```

依畫面指示選擇包含 PDF 的資料夾、輸入研究主題，即可開始建立文獻地圖。

## 隱私

你的本機 PDF 與建立的文獻資料保留在自己的電腦中。工具可在未設定外部服務金鑰的情況下使用基本功能。
